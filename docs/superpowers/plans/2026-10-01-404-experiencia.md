# El 404 como experiencia: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the bilingual `global-not-found` with a per-language 404 that has a real 404 status. Its experience: the hero glass shatters (Remotion), its fragments become a live 3D constellation of the site's pages (React Three Fiber), and the page keeps the full agent site map.

**Architecture:**
- For unknown HTML paths, `src/proxy.ts` fetches a prerendered per-language «molde» (`app/[lang]/perdido`) and returns its HTML with status 404, its own cache headers, and a self-contained fallback if the fetch fails.
- The molde is server-complete: text, seven fragment links and the `#mapa` section.
- On top of the molde, in order:
  1. a Remotion-rendered alpha video of the shatter;
  2. the R3F scene, mounted at the video's exact last frame thanks to a shared shard config;
  3. a static constellation image, which stays when motion or 3D isn't allowed.

**Tech Stack:** Next.js 16.2 (`proxy.ts`), React 19, TypeScript strict, Tailwind 4, `three` + `@react-three/fiber` + `@react-three/drei` (app, lazy), and Remotion (`remotion`, `@remotion/cli`, `@remotion/three`) in a separate `video/` project that is not deployed. Tests use Vitest, Playwright and axe.

**Spec:** `docs/superpowers/specs/2026-10-01-sgomez-404-experiencia-design.md`. It builds on `docs/superpowers/specs/2026-09-30-sgomez-redesign-design.md` and on the phase 1 rulings in `.superpowers/sdd/2026-09-30-redesign-fase-1-cimientos/progress.md`.

## Global Constraints

- An unknown URL returns **status 404**, in the URL's language: `/en/…` in English, everything else in Spanish. It uses that language's Nav, Footer and `<html lang>`.
- 404 HTML response headers:
  - `Content-Type: text/html; charset=utf-8`
  - `Cache-Control: public, max-age=60, s-maxage=60`
  - `Vary: RSC, Next-Router-State-Tree, Next-Router-Prefetch, Next-Router-Segment-Prefetch, Accept, Accept-Encoding` (= `PAGE_VARY`)
  - `X-Robots-Tag: noindex, follow`
- Bypass header for the internal molde fetch: `x-sgomez-404: 1`. The proxy never re-fetches when it is present.
- The molde cache in the proxy is per language, with a TTL of 60 s. If the fetch fails, the proxy serves a self-contained fallback HTML 404, never a 500.
- `Accept: text/markdown` and unknown `.md` keep returning `notFoundMarkdown(path, lang)`, unchanged.
- Remove `src/app/global-not-found.tsx` and `experimental.globalNotFound`.
- Copy, with NO dashes (· - --) and no rhetorical colons:
  - ES: label «Error 404 · {ruta}», title «Esta página» + serif «se ha roto.», body «Pero cada fragmento lleva a un sitio que sí existe. Elige uno o vuelve al inicio.», buttons «Volver al inicio» and «Ver el mapa completo».
  - EN: label «Error 404 · {path}», title «This page» + serif «broke.», body «But every fragment leads somewhere that exists. Pick one or head home.», buttons «Back to home» and «See the full map».
  - The requested path is read client-side from `location.pathname`, rendered as text and truncated to 80 chars. Without JS, the label is just «Error 404».
- Seven linked fragments, built from the route catalogue and `machineHref`, never hand-written:
  1. Inicio / Home
  2. Sobre mí / About
  3. Proyectos / Work (`/#work`)
  4. Open source (`/#open-source`)
  5. Contacto / Contact (`/#contact`)
  6. Developers
  7. Para agentes / For agents (the language's `llms.txt`)

  Plus 4-5 decorative shards without links.
- The owner's name is never «Santiago Gómez» alone.
- Budgets:
  - LCP < 2.5 s (the title or poster, never the canvas);
  - initial JS ≤ 170 KB gzip;
  - R3F chunk lazy ≤ 250 KB gzip;
  - all video files together ≤ 1.5 MB;
  - CLS < 0.05.
- Accessibility: axe clean; visible focus; 44 px targets; AA contrast in every state; a «Pausar movimiento» / «Pause motion» control; `prefers-reduced-motion`, no-WebGL, Save-Data and no-JS all get the complete static constellation with the same links.
- Responsive at 320-1920 px and 844×390, with no page-level horizontal scroll. On mobile the constellation stacks under the text.
- Every `<Link>` has `prefetch={false}`. No function props go into `'use client'` components. Every UI string is in both dictionaries.
- Remotion renders locally only, with no cloud or paid service. Generated media is committed.
- Commits use the repo's git author with NO `Co-Authored-By` or any trailer. No push.

## Review Focus

1. **A bot probing many random paths:** each unknown path must not cost an extra origin fetch once the molde is cached. Task 1 has a unit test showing two 404s within the TTL make one fetch.
2. **The molde fetch fails** (preview protection, timeout, 500): the visitor still gets a 404 with links, not a 500 or a blank page. Task 1 has a unit test with `fetch` rejecting and returning 500.
3. **Unknown asset paths** (`/foo.png`, `/_next/x.js`, `/api/nope`) must NOT get the HTML experience. They keep their existing 404 (plain, or JSON for `/api`). Task 1 has unit cases on `isUnknownHtmlPath`.
4. **Client navigation** from a page to an unknown link must end on the localized 404 with no console errors, through a hard navigation. Task 5 has an e2e test.
5. **Video and scene handoff** when the video is cached or ends before the 3D chunk loads, or the 3D chunk fails to load: no blank stage and no jump. The static constellation must remain until the scene reports ready. Task 4 has unit tests of the sequence state machine and an e2e test with the R3F chunk blocked.

```ts
import { PAGES } from "@/lib/routing/pages";

/** A public HTML path that matches no page. Files, /api, /_next and machine files are never "unknown HTML". */
export function isUnknownHtmlPath(pathname: string): boolean {
  if (pathname.startsWith("/_next") || pathname === "/api" || pathname.startsWith("/api/")) return false;
  if (NEGOTIATION_EXEMPT_PATHS.includes(pathname) || FILE.test(pathname)) return false;
  const { path } = splitLang(pathname);
  if (path === "/opengraph-image") return false;
  return !(PAGES as readonly string[]).includes(path.replace(/\/$/, "") || "/");
}
```

`src/lib/lost/molde.ts`:

```ts
import type { Lang } from "@/i18n/languages";
import { notFoundMarkdown } from "@/lib/markdown/documents";
import { SITE_URL } from "@/lib/site";

export const BYPASS_HEADER = "x-sgomez-404";
export const MOLDE_PATH: Record<Lang, string> = { es: "/es/perdido", en: "/en/perdido" };
const TTL_MS = 60_000;
const cache = new Map<Lang, { html: string; at: number }>();
export function __resetMoldeCache() { cache.clear(); }

export async function fetchMolde(lang: Lang, origin: string, fetchImpl: typeof fetch = fetch, now: () => number = Date.now): Promise<string | null> {
  const hit = cache.get(lang);
  if (hit && now() - hit.at < TTL_MS) return hit.html;
  try {
    const res = await fetchImpl(new URL(MOLDE_PATH[lang], origin), { headers: { [BYPASS_HEADER]: "1" }, cache: "no-store" });
    if (res.status !== 200) return null;
    const html = await res.text();
    cache.set(lang, { html, at: now() });
    return html;
  } catch {
    return null;
  }
}

const esc = (s: string) => s.replace(/[&<>"']/g, (c) => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;", '"': "&quot;", "'": "&#39;" })[c]!);

/** Self-contained 404 used when the molde can't be fetched. Built from the same site map as the markdown 404. */
export function fallback404Html(path: string, lang: Lang): string {
  const md = notFoundMarkdown(path, lang);
  const links = [...md.matchAll(/\[([^\]]+)\]\((https?:\/\/[^)]+)\)/g)].map(([, t, h]) => `<li><a href="${esc(h!)}">${esc(t!)}</a></li>`).join("");
  const title = lang === "en" ? "This page doesn't exist" : "Esta página no existe";
  return `<!doctype html><html lang="${lang}"><head><meta charset="utf-8"><meta name="viewport" content="width=device-width,initial-scale=1"><meta name="robots" content="noindex,follow"><title>404 · sgomez.dev</title><style>body{margin:0;background:#05060A;color:#F4F6FB;font:16px/1.6 system-ui,sans-serif;padding:48px 24px}a{color:#8FA8FF}main{max-width:680px;margin:auto}</style></head><body><main><p>Error 404 · ${esc(path.slice(0, 80))}</p><h1>${title}</h1><ul>${links}</ul><p><a href="${SITE_URL}${lang === "en" ? "/en" : "/"}">${lang === "en" ? "Back to home" : "Volver al inicio"}</a></p></main></body></html>`;
}
```

**Interfaces:**
- Consumes: `SHARDS`, `CAMERA`, `LINES`, the media from Task 3, and `data-shard-id` anchors from Task 2.
- Produces:

```ts
// src/chapters/lost/sequence.ts · pure
export type Phase = "static" | "video" | "scene" | "idle";
export type Event = "motionAllowed" | "videoEnded" | "videoFailed" | "sceneReady" | "sceneFailed" | "pause" | "resume";
export function next(phase: Phase, event: Event, ctx: { sceneReady: boolean }): Phase;
```

Rules:
- Start at `static`.
- `motionAllowed` → `video`, only if gating passes. Gating means WebGL2, no `prefers-reduced-motion`, no Save-Data, and `hardwareConcurrency ≥ 4`; it's checked in `LostExperience`, not here.
- `videoEnded` → `scene` if `ctx.sceneReady`. Otherwise stay on the poster-end frame until `sceneReady` → `scene`.
- `videoFailed` → keep the static layout, and go to `scene` when it's ready.
- `sceneFailed` → `static` (final).
- `pause` freezes motion in the current phase: the video pauses and the scene stops animating.
- `idle` = the scene running.

`LostExperience`:
- It is the only new client component on this page. It receives only strings and `lang`.
- It renders the `<video>` (webm source + mp4/mov source, `muted playsInline`, no `autoplay` until gating) over the static layer.
- It loads `ConstellationScene` via `next/dynamic({ ssr: false })` in parallel with the video.
- When the scene reports ready and the video has ended, it crossfades over 200 ms. The static `<a>` fragments STAY in the DOM and become the overlay links: each frame, the scene calls a `onProject(id, x, y)` callback-ref.
  - Careful: no function props from server to client. The callback lives entirely inside `LostExperience`, which is the client component that owns both the scene and the anchors.
  - It sets `transform: translate()` on the matching `[data-shard-id]` anchor.
- It renders the pause button (44 px, dictionary label, `aria-pressed`).

`ConstellationScene`:
- R3F `<Canvas>` with `CAMERA`, `dpr={[1, 1.75]}`, alpha.
- The 12 shards use the same material as Task 3 and are placed at `pose`.
- Idle float: a per-shard sine with distinct phase, amplitude ≤ 0.08 units.
- Pointer tilt: damped, up to 6°.
- Gyro tilt, only after a user gesture with permission on iOS (a «Mover con el móvil» / «Tilt with your phone» button appears only where `DeviceOrientationEvent.requestPermission` exists).
- Hover or focus on an anchor makes the matching shard glow (emissive up and scale ×1.08). This is wired through a `highlightId` prop, which is a string, not a function.
- `LINES` is drawn with `Line` from drei at 0.28 opacity.
- It calls `onReady` after the first frame.
- It disposes on unmount.

Budgets:
- the R3F chunk is ≤ 250 KB gzip (measure it in the build output or with a Playwright request listener on `/en/no-existe`);
- the initial JS stays ≤ 170 KB (the existing e2e budget must also run on `/en/no-existe`).
